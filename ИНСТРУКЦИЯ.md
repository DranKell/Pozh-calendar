# 📋 ИНСТРУКЦИЯ ПО ЭКСПЛУАТАЦИИ И РАЗВЁРТЫВАНИЮ «КАЛЕНДАРЬ ТО»

Программный комплекс **«Календарь ТО»** предназначен для планирования, диспетчеризации и финансового учёта технического обслуживания инженерных систем и противопожарной защиты объектов в строгом соответствии с нормами пожарной безопасности (ПБ), ГОСТ, СП и требованиями МЧС России (включая 123-ФЗ, ППР РФ № 1479, СП 484/485/486/3/10/7.13130).

---

## 🚀 БЫСТРЫЙ СТАРТ (ДЛЯ WINDOWS)

### 1. Первоначальная установка (в один клик)
Запустите файл **`install.bat`** двойным кликом. Скрипт:
- Самостоятельно проверит наличие Python в системе.
- **Если Python отсутствует**: автоматически скачает официальный дистрибутив Python 3.11 и установит его в тихом режиме с параметром `PrependPath=1` (добавление в системную переменную PATH).
- Создаст виртуальное окружение `.venv` и установит все библиотеки из `requirements.txt` (с автоматическим переключением на резервное зеркало при сбоях сети).
- Инициализирует базу данных SQLite и загрузит нормативно-справочную базу регламентов ПБ (`seed.py`).

### 2. Открытие порта для локальной сети (для Windows Server 2025 / Windows 10/11)
Если к системе будут подключаться другие компьютеры в офисе/сети:
- Запустите от имени Администратора файл **`open_firewall_port.bat`** (он разрешит входящий TCP-порт 9000 в Брандмауэре Windows Defender).

### 3. Запуск приложения
Запустите файл **`run.bat`** (или выполните команду `python run.py`).
- Локально на сервере: **http://localhost:9000**
- С других рабочих мест в сети: **http://<IP_АДРЕС_СЕРВЕРА>:9000**
- Порт и адрес привязки настраиваются в файле `config.json` в секции `"server": { "host": "0.0.0.0", "port": 9000 }`.

## 🧭 РУКОВОДСТВО ПО ФУНКЦИОНАЛУ

### 1. Дашборд
- Отображает общие показатели: количество обслуживаемых объектов, виды работ (регламенты ПБ), активные договоры, выполнение плана на текущий месяц и просрочки.
- Блоки «Ближайшие работы» и «Просроченные» позволяют в один клик перейти к объекту или карточке выполнения.

### 2. Объекты и интеллектуальный ИИ-импорт
- Ведение реестра площадок (ТЦ, офисы, склады, производства, школы, больницы, жилые комплексы и др.).
- Реквизиты: адрес, контактное лицо, телефон, email, ИНН.
- **Интеллектуальный ИИ-импорт объектов**:
  - На вкладке **«Объекты»** кнопка **«📥 Импорт через ИИ»** предназначена для добавления обслуживаемых объектов и контрагентов-заказчиков:
    1. **Вставленным текстом**: списки площадок, реквизиты, адреса, таблицы.
    2. **Прикреплённым документом**: поддерживаются Word (`.docx`, `.doc`), Excel (`.xlsx`, `.xls`), Adobe PDF (`.pdf`), TXT и CSV. Добавлена аппаратная защита от сбоев при парсинге бинарных ZIP/PDF-контейнеров.
  - **Наглядная индикация процесса**: во время чтения документа прямо внутри зоны загрузки отображается светящийся анимированный круговой индикатор (спиннер) с пояснением этапа обработки (извлечение таблиц, поиск реквизитов, расчёт пожарной опасности по 123-ФЗ).
  - Нейросеть (YandexGPT или GigaChat в отказоустойчивой схеме «или/или», либо встроенная нормативная база 123-ФЗ) автоматически извлекает наименования, ИНН, КПП, ОГРН, адреса, телефоны, email, рассчитывает площади, этажность, классы функциональной пожарной опасности (**ФПО** по 123-ФЗ) и категории взрывопожароопасности.
  - Список **автоматически сортируется по организациям (по алфавиту)** и сохраняется в реестр объектов ТО.
- **Параметры пожарной безопасности**:
  - Класс функциональной пожарной опасности (**ФПО**: Ф1.1–Ф5.3 по ст. 32 123-ФЗ).
  - Категория взрывопожароопасности (**А, Б, В1–В4, Г, Д** по СП 12.13130).
  - Общая площадь (м²) и этажность здания.
- **Живой поиск**: мгновенная фильтрация по названию, адресу и реквизитам.
- Карточка объекта содержит сводку по всем договорам, детальный прогресс выполнений, финансовый баланс и кнопку запуска экспертного ИИ-аудита.

### 3. Справочник регламентов и норм ПБ (Шифры ПБ-XX.YY)
- Отраслевая номенклатура работ с классификацией по системам безопасности:
  - `ПБ-01.XX` — Пожарная сигнализация (АПС) и оповещение (СОУЭ).
  - `ПБ-02.XX` — Первичные средства пожаротушения (огнетушители, пожарные щиты).
  - `ПБ-03.XX` — Противопожарный водопровод (ВПВ) и пожаротушение (АУПТ, газ).
  - `ПБ-04.XX` — Противодымная вентиляция (ДУ) и очистка вентканалов.
  - `ПБ-05.XX` — Эвакуационные пути, выходы и фотолюминесцентные планы.
  - `ПБ-06.XX` — Электролаборатория (ЭТЛ), молниезащита, резервное питание.
  - `ПБ-07.XX` — Противопожарные инструктажи и обучение ответственных лиц.
  - `ПБ-08.XX` — Разработка документации и комплексный аудит ПБ.
  - `ПБ-09.XX` — Противопожарные двери и огнестойкие преграды.
  - `ПБ-10.XX` — Экстренное реагирование и выезд инженера ПБ.
- Добавление собственных услуг с указанием шифра, цены, периодичности и требуемой квалификации (Лицензия МЧС, СРО, Лицензия ЭТЛ).

### 4. Назначения и автопланирование
- Привязка регламента к объекту с выбором периода (например, на календарный год) и периодичности.
- Система **автоматически строит точный график дат** с защитой от сдвига дней в месяцах разной длительности (`add_months_anchor`).
- Возможность перегенерации расписания (`↻`) с гарантированным сохранением уже закрытых фактов ТО.

### 5. Интерактивный Календарь
- Просмотр сетки событий на любой месяц с цветовой индикацией статусов:
  - 🔵 **Синий** — запланировано
  - 🟢 **Зелёный** — выполнено
  - 🟡 **Жёлтый** — перенесено
  - 🔴 **Красный** — просрочено
  - ⚫ **Серый** — отменено
- **Модальное окно дня**: детальный список назначенных работ с функцией **пакетного закрытия в один клик** («Выполнить все»).

### 6. Мультиорганизации, Счета и Акты выполненных работ
- **Разделение логики импорта (Объекты vs Счета)**:
  - В модальном окне «Счета» доступна собственная кнопка **«📥 ИИ-импорт организации»**.
  - Позволяет загружать официальные «Карточки сведений / реквизитов предприятия» (в формате `.docx`, `.xlsx`, `.pdf` или текстом) для регистрации **наших исполнителей**.
  - Алгоритм извлекает полные банковские реквизиты: Расчётный счёт (р/с), Корр. счёт (к/с), БИК, Наименование банка, ИНН, КПП, ОГРН, Юридический адрес и данные подписанта (Генеральный директор / Директор).
- **Выставление счёта от разных юридических лиц**: при создании счёта выбирается организация-исполнитель из реестра или создаётся новая.
- **Управление организациями (`/api/companies`)**:
  - Полные реквизиты: Название, ИНН, КПП, ОГРН, Юридический адрес.
  - Банковские реквизиты: БИК, Банк, Расчетный счёт (р/с), Корреспондентский счёт (к/с).
  - Подписанты: Руководитель (должность и ФИО), Главный бухгалтер.
  - Налоги и нумерация: ставка НДС (без НДС / 20%), индивидуальный префикс счетов (например, `СЧ-`, `ПБ-`, `ТО-`).
  - Флаг организации по умолчанию.
- **Взаиморасчёты**: автоматический расчёт задолженности по объекту, фиксация оплат (полная или частичная).
- **Печать документов в строгом бухгалтерском виде**:
  - **«🖨 Счёт»** — официальный счёт на оплату с реквизитами выбранной организации, суммой прописью и блоками подписей.
  - **«📄 Акт»** — двусторонний акт сдачи-приемки оказанных услуг с расшифровкой работ и суммами.

## 🤖 ИИ-ПОМОЩНИК И ЭКСПЕРТНЫЙ АУДИТ ОБЪЕКТОВ

В системе реализован гибридный интеллектуальный контур:

### 1. Индикатор статуса в шапке (строго двухцветный, без раздражающих цветов):
- 🟢 **Зеленый** (`[ОНЛАЙН]`): подтверждено реальное подключение к внешней LLM (`YandexGPT` или `GigaChat`). В шапке отображается название именно той модели, которая сейчас активна.
- 🟡 **Оранжевый / Тёплый янтарь** (`[123-ФЗ] / [БЕЗ API]`): внешний ключ отсутствует или недоступен. Система автоматически переходит на встроенную нормативную базу экспертных правил МЧС и 123-ФЗ.

### 2. Реальная проверка подключения (Live Health-Check) и отказоустойчивость («Или / Или»):
- При запуске и по кнопке проверки сервер проверяет доступность внешних API реальным запросом (для Сбер GigaChat выполняется полноценный OAuth-обмен сертификата на Bearer-токен с обходом локальных SSL-ошибок Минцифры, для YandexGPT — проверка IAM/API-Key и Catalog ID).
- **Схема «Или / Или» (Failover)**: настроена работа по цепочке `providers = yandexgpt, gigachat`. Если первая модель не указана, исчерпала лимиты или выдает сетевую ошибку — система автоматически и прозрачно переключается на вторую. Если недоступны обе — бесшовно включается локальная база 123-ФЗ.
- **Никаких вымышленных данных**: в системе категорически запрещены заглушки («ООО Ромашка», тестовые адреса). Применяются только реальные нормативы и фактические данные объектов.

### 3. Интеллектуальный аудит объекта:
- Сопоставляет характеристики объекта (ФПО, категорию взрывопожароопасности, площадь, этажность) с нормами СП 484/485/486/3/10.13130 и ППР РФ № 1479.
- Выявляет обязательные нормативные регламенты, которых ещё нет в плане обслуживания объекта.
- Формирует экспертное заключение с кликабельными бейджами категорий и кнопками добавления работ в план в один клик.

## 🔔 СИСТЕМА УВЕДОМЛЕНИЙ И ИНТЕГРАЦИЯ С MAX MESSENGER

### 1. Интерактивный колокольчик в веб-интерфейсе:
- В правом верхнем углу расположен значок `🔔` со счетчиком актуальных напоминаний.
- **Инспекторские правила напоминаний (за 10, 7, 3, 1 дней)**: система отслеживает регламентные сроки ТО и формирует предписания за 10, 7, 3 и 1 день до даты проведения.
- **Смещение выходных**: если расчетный день напоминания выпадает на субботу или воскресенье, напоминание автоматически смещается на **предшествующую пятницу**, чтобы ответственные сотрудники получили предупреждение до ухода на выходные.
- **Управление уведомлениями**:
  - Клик по напоминанию открывает календарь на нужной дате и снимает уведомление.
  - Кнопка закрытия `✕` у каждого уведомления.
  - Кнопка **«Прочитано всё»** для быстрой очистки списка.
  - Звуковое оповещение Web Audio API с корректным разрешением политик автовоспроизведения браузера (включение/выключение кнопкой `🔊 / 🔇`).

### 2. Внешний канал: Мессенджер MAX (MAX Bot API)
- Модуль рассылок `app/services/notifier.py` интегрирован с платформой **MAX** (`https://platform-api2.max.ru`).
- Настройки хранятся в `msg.cfg` в блоке `[max_messenger]`:
  - `api_url = https://platform-api2.max.ru`
  - `bot_id = id5921029563_bot`
  - `bot_token = <секретный токен бота>`
  - `default_chat_id = 5741854` (или `user_id` дежурного диспетчера / инженера)
- **Умная анти-спам группировка оповещений (Smart Batching)**:
  - **Если через N дней запланирован 1 объект**: отправляется подробная карточка проверки с названием, фактическим адресом, шифром и наименованием регламента, оставшимся сроком и предписанием инспектора.
  - **Если запланировано 2 и более объектов (вплоть до десятков)**: система автоматически объединяет их в **единый сводный дайджест**. Сообщение содержит нумерованный список площадок, их реальные адреса, виды работ, ответственных лиц с телефонами и общее требование пожарной безопасности (п. 54 ППР № 1479). Это гарантирует отсутствие спама и исключает превышение лимитов API.

### 3. Электронная почта (SMTP):
- Блок `[email]` в `msg.cfg` (SSL/TLS, хост, порты 465/587, логин, пароль приложения, адресаты TO, CC, BCC) для отправки сводок на корпоративную почту.

## 💡 ИНТЕРАКТИВНЫЙ ГИД, ПОДСКАЗКИ И ИИ-КОНСУЛЬТАНТ

Для быстрого погружения новых сотрудников и диспетчеров в интерфейс встроена справочная система:
- **Кнопка «💡 Помощь»** в шапке навигации (с плавной подсветкой и быстрым вызовом).
- **Вкладка «5 шагов работы»**: наглядный интерактивный регламент с пошаговым обучением:
  1. **Шаг 1. Создание или импорт объекта**: внесение адреса, ФПО, площади или быстрый импорт списком через ИИ.
  2. **Шаг 2. Настройка услуг и регламентов ПБ**: выбор видов работ из каталога (АПС, СОУЭ, ВПВ, ЭТЛ и др.).
  3. **Шаг 3. Автогенерация графика**: создание годового плана ТО с защитой от сдвига дат.
  4. **Шаг 4. Учёт и закрытие фактов ТО**: фиксация актов, перенос дат с выбором дня и отслеживание в интерактивном календаре.
  5. **Шаг 5. Счета, акты и мультиорганизации**: выставление документов от нужного юрлица, печать счетов и актов А4.
  * *Примечание:* Данный блок является **полностью справочным и ненавязчивым** — его можно открыть или закрыть в любой момент, а также свернуть кнопкой «Понятно, к работе!».
- **Вкладка «✨ Все функции и перенос»**: полный обзор продвинутых возможностей:
  - Финансовый контроль и KPI в разделе «Счета»: План/факт выручки, дебиторка, процент соблюдения сроков (SLA).
  - «Журнал ТО» и автоподбор объектов: живой фильтр по названию объекта прямо при вводе с клавиатуры.
  - Журнал по ППР РФ № 1479 и официальные Акты технического освидетельствования (печать А4 и выгрузка в Excel).
  - Экспертные рекомендации ИИ по СП и 123-ФЗ с селективным выбором («✓ Назначить выбранные» / «⚡ Назначить все»).
  - Ограничение отправки уведомлений по рабочему времени (с 08:00 до 18:00).
  - Памятка по переносу на другой сервер без потери данных.
- **Вкладка «ИИ-консультант»**: диалог с быстрыми вопросами и полем ввода. Консультирует по статьям 123-ФЗ, СП 484/486/3/10, классам ФПО и функционалу системы. Работает как через подключенную LLM (YandexGPT / GigaChat), так и автономно по экспертной базе 123-ФЗ.
- **Вкладка «Цвета и статусы»**: расшифровка цветовой индикации событий в календаре (синий, зеленый, янтарный, красный).

|---|---|---|
| **Backend** | Python 3.10+, FastAPI | Асинхронный REST API, валидация Pydantic v2 |

| **Печать и отчеты** | Чистый CSS `@media print`, Excel (.xlsx) | Печать счетов, актов А4, Журнал ППР 1479 и Акты освидетельствования |
| **Конфигурация**| `config.json`, `msg.cfg` | Сеть, реквизиты, почта, мессенджер, LLM-ключи |

### 📦 Инструкция по переносу на другой сервер

1. **Файлы архива**:
   - Архив **`PROD_Calendar_ready.zip`** уже собран и очищен от временных файлов, кэшей `__pycache__`, виртуального окружения и тестовых данных.
   - В архиве находятся готовые скрипты развёртывания `install.bat`, `run.bat`, `open_firewall_port.bat`, чистая база данных `data/app.db` и шаблон настроек `msg.cfg.example`.
2. **Развёртывание на новом сервере (Windows Server 2022/2025 / Win 10/11)**:
   - Распакуйте архив в целевой каталог (например `C:\Apps\PROD_Calendar`).
   - Скопируйте файл `msg.cfg.example` в `msg.cfg` (или перенесите ваш настроенный `msg.cfg` с токенами).
   - Запустите **`install.bat`** от имени пользователя или администратора. Скрипт проверит/установит Python 3.11, развернёт `.venv` и установит библиотеки `requirements.txt`.
   - Если сервер должен быть доступен по локальной сети, запустите от Администратора **`open_firewall_port.bat`** (откроет порт 9000 в Windows Defender).
   - Запустите комплекс через **`run.bat`**.
3. **Развёртывание на Linux (Ubuntu / Debian / Astra Linux)**:
   ```bash
   unzip PROD_Calendar_ready.zip -d /opt/prod_calendar
   cd /opt/prod_calendar
   cp msg.cfg.example msg.cfg
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python run.py
   ```
   Веб-интерфейс будет доступен по адресу `http://<IP_СЕРВЕРА>:9000`.
